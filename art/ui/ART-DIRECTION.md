# Neighborhood grocery UI

Built-in image generation produced the concept (`market-ui-concept.png`) and the shipped emblem (`../../UnityGame/Assets/Resources/UI/grocery-emblem.png`). Original generated alpha is preserved. Unity imports the emblem at up to 512 px; the full-resolution source remains in the project.

The live game implements the concept with editable Lato typography, cream paper cards, forest-green outlines, tomato and yellow sticker buttons, a packing progress meter, leafy accents, and a receipt result screen. Buttons depress on press; stars pop in sequentially. Code draws the reusable shapes and icons. The concept image is a reference, not a game background; it depicts an illustrative environment beyond this UI pass.

Palette: cream #FFF4D8, forest #234D38, tomato #D6503B, sun #F6C65C, sage, kraft.

## Concept prompt

Use case: ui-mockup. Create a polished landscape art-direction concept for a Unity casual grocery-packing puzzle called 'Bagging Order'. Playful neighborhood grocery store, charming editorial paper-cut illustration blended with simple isometric 3D groceries. Actual gameplay occupies the large uncluttered center: a cutaway kraft paper bag with four packing levels and a conveyor of groceries below. Design beautiful small corner UI instead of a website header/navigation: upper left a small paper bag emblem and chunky friendly BAGGING ORDER wordmark, below it a cream price-tag level card reading '01 / A sturdy start'; upper right a small green packed counter; bottom a narrow cream control strip with tactile colored sticker buttons 'Undo', 'Restart', 'Bags', 'Sound'. Beside selected grocery two playful chunky buttons 'Turn' and 'Tip'. Include a small receipt-shaped completion panel inset on the right with three sunny star stickers and 'Beautifully bagged!'. Palette cream #FFF4D8, forest green #234D38, tomato red #D6503B, sunny yellow #F6C65C, kraft tan. Consistent rounded corners, offset dark-green shadows, subtle paper texture, dark readable typography, decorative tiny leaf and sparkle details only around corners. Friendly contemporary game art, not childish, not glossy plastic. No marketing page, no paragraphs, no browser frame. This is a visual concept to guide separately implemented live UI.
